A launch-day Twitch audience forecaster: given the first hour's viewer print for Grand Theft Auto VI's release day plus the launch curves of 42 past big game launches, it forecasts hours 2 to 24 as five quantiles each. It anchors on the hour-1 print, separates launches whose hour 1 was already live from launches whose unlock was still ahead, weights past launches by similarity in scale and pre-launch trend, and pools their hour-by-hour log-ratio curves into calibrated quantiles. Standard library only, deterministic, no network.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
